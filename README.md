# GEOG 328 Spatial Interpolation Tools

Two interactive teaching tools for GEOG 328:

- `index.html`: inverse distance weighting (IDW), including power, search neighborhood, output cell size, sampling strategy, barriers, and neighborhood shape.
- `spline.html`: one-dimensional interpolating B-splines of polynomial degree 1–5, spatial radial spline kernels of order 1–3, and a side-by-side comparison with IDW (α = 2, all samples). Students can also explore sample spacing, global and local fits, and exact and approximate fits.

Both pages include group discussion questions. The observations are fictional. The tools use only local HTML, CSS, and JavaScript, with no external runtime dependencies.

Public pages: [IDW](https://twin22jw.github.io/geog328-idw-explorer/) and [Spline](https://twin22jw.github.io/geog328-idw-explorer/spline.html).
