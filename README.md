# GEOG 328 Spatial Interpolation Tools

Two interactive teaching tools for GEOG 328:

- `index.html`: inverse distance weighting (IDW), including power, search neighborhood, output cell size, sampling strategy, barriers, and neighborhood shape.
- `spline.html`: a one-dimensional cubic spline transect plus a two-dimensional thin-plate spline surface. Students can explore global and local fits, exact and approximate fits, gradual and abrupt patterns, illustrative stochastic realizations, and a side-by-side comparison with IDW (α = 2, all samples).

Both pages include group discussion questions. The observations are fictional. The stochastic spline view is an illustrative simulation rather than an uncertainty estimate. The tools use only local HTML, CSS, and JavaScript, with no external runtime dependencies.

Public pages: [IDW](https://twin22jw.github.io/geog328-idw-explorer/) and [Spline](https://twin22jw.github.io/geog328-idw-explorer/spline.html).
